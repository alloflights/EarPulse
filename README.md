# earuseage

一款基于 **SwiftUI + Swift Charts + HealthKit** 的 iOS 原生耳机使用时间统计应用，采用 iOS 26 液态玻璃（Liquid Glass）视觉与中英双语界面。

## 核心功能

- **真实数据同步**：直接读取 Apple 健康中的耳机音频暴露记录（支持首次授权后静默自动同步），或一次性导入 `export.xml` 永久缓存。
- **统计视图**：过去一周每日佩戴时长柱状图与平均参考线；点选任意一天可查看当日 24 小时逐小时、按耳机分色堆叠的使用明细。
- **设备管理**：横向滑动耳机卡片展示各副耳机真实产品图、累计时长与主力耳机标注；点击卡片可查看单款耳机的总览与个人最长记录，支持自定义排序及多设备数据合并。
- **实时限额提醒**：自定义每日佩戴限额与单次连续佩戴限额，结合实时音频路由计时，达限时触发本地通知与震动反馈。
- **开屏动画**：启动时按当前耳机型号自动播放仿系统开盖弹窗动画。

## 构建说明

- **iOS 打包**：推送至 GitHub 后由 `.github/workflows/build-ipa.yml`（`macos-26`）自动构建 `EarPulse.ipa`。
- **Mac 预览**：双击项目根目录下的 `Mac预览.command` 即可直接启动原生 SwiftUI 预览窗口。
