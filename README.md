# earuseage

一款基于 SwiftUI + Swift Charts + HealthKit 的 iOS 耳机使用时间统计应用，支持液态玻璃界面与中英双语。

## 核心功能

- **数据同步**：读取 Apple 健康耳机音频暴露记录，支持导入 `export.xml`。
- **统计视图**：查看每日佩戴时长柱状图、24 小时逐小时使用明细与平均分贝。
- **设备管理**：展示各副耳机累计时长、单设备详情、自定义排序与数据合并。
- **限额提醒**：自定义每日与单次佩戴限额，达限时触发本地通知与震动。
- **桌面小组件**：提供小号与中号小组件展示今日佩戴时长、频次与分贝。
- **开屏动画**：启动时按当前耳机型号播放开盖弹窗动画。
